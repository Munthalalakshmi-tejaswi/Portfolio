Project details

CineVault · Mini Netflix

Android application · Java

Browse movie trailers. Play them instantly.

CineVault (Mini Netflix) is a dark-themed Android application for browsing a curated catalog of movies, viewing each movie’s details, and playing its trailer in the app. The project demonstrates RecyclerView-based lists, serializable data passing, and Android video playback.

App experience

Splash screen

Opens with branded launch screen and a three-second transition.

Home menu

Provides navigation to Browse, Search, and Profile.

Movie catalog

Displays five selected movies with posters in a scrollable list.

Details and playback

Selecting a movie opens its details and plays the trailer with built-in Play, Pause, and Seek controls.

Tech stack

Java Android XML layouts RecyclerView VideoView MediaController Gradle 8.8 Android API 35+ MIT License

The layout uses ConstraintLayout and LinearLayout. A custom RecyclerView adapter renders the catalog; Serializable movie data is passed to the detail screen, where VideoView and MediaController handle playback.

Project structure

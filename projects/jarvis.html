Jarvis AI Assistant

Voice + AI chat

A hands-free assistant with useful everyday tools

Jarvis is a voice-controlled assistant built with HTML, CSS, and JavaScript in its browser version. It combines speech recognition, spoken responses, and interface updates. Related project versions add AI chat capabilities and a Python-and-SQL implementation.

Project demo videos

Watch the different Jarvis and chat-mode implementations.

What it can do

Voice and chat

Listen to spoken commands, accept typed messages in chat-enabled versions, and respond with text, voice, and UI updates. The assistant can greet users and answer AI or general knowledge questions.

Website controls

Open Google, YouTube, Facebook, Instagram, WhatsApp Web, Wikipedia, and YouTube Music with voice commands.

Everyday utilities

Report the current time and date, calculate simple expressions, check battery level and charging status, and search Google when a command is not recognized.

Helpful extras

Look up country facts such as capital, currency, region, population, and languages; add tasks to a to-do list with voice confirmation; and tell programming or student-friendly jokes.

Example commands

Say or typeJarvis responds by
“Open Google” / “Open YouTube”Speaking a confirmation and opening the requested site.
“Time” / “Date”Reporting the current time or date.
“Calculate 5+5”Evaluating a simple math expression.
“Battery”Showing battery percentage and charging status where supported.
“Tell me about Japan”Sharing country facts, including capital, currency, region, population, and languages.
“Add task finish assignment”Adding a task to the to-do list and confirming it by voice.
“Joke” / “Jokes for students”Telling a programming joke or a student-friendly joke.
“What is AI?” or another queryProviding an answer in AI chat mode or searching Google for an unrecognized command.

How to use the browser version

  1. 01Open index.html in Chrome or Edge.
  2. 02Click the microphone button or type a message in chat mode.
  3. 03Try a command above and follow Jarvis’s voice and on-screen response.
